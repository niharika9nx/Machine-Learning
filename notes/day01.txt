Classification:

Tyeps of Classification:

Unsupervised learning:
Here the training is done using unlabelled DATA

Unsupervised learning is divided into:

    2. Association

Clustering:
We group the data based on similarity in the data points
we call them as a "Cluster"
- cosine similarity (keyword)

Types of clustering:

    - K-mean's

Assocaition:
chances of occuring of a thing based on the previous one 
online definition - Find rules about which items occur together. "If X happens, Y tends to happen too."

In data,
The feature (part of data) which contributes high to the prediction is important

sigma (standard deviation) = sqrt(variance) 

The nature of model we need to have as a target to achieve in our project -

BIAS -
meaning = error
what if the feature which has high variance still resulted in wrong output - this is the bias

overfitted model
- understands patterns
- passes in training
- fails in tests

underfitted model (high bias model) 
- unable to understand pattern
- fails in training

What is learning
    - Optimization of parameters
    - we train the model to find out the relation between x and y and in that process the we will find out the parameter values
y = actual
y! = predicted 
y! - y = error
error = how far our model is from the original value
our goal = reduce the error
i.e, y! =(nearly equal to) y
to achieve this we "train the model"
