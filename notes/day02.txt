suppose we have a table of data with functions, for training the model we create an equation of these function swith some weights , so now for adusting the weights we will be panelizing
1. method one is dividing the equation with sum of the whole coefficients
2. Dividing with sum of the squares of the coefficients

names of the penalty
L1 - Lasso 
L2 - Ridge

L1 - is also a feature selction technique 
    - it eliminates the low contributing feature (as the division happens the value nearly tends to zero)
    - Can push weights exactly to zero → automatic feature selection, sparse models.
L2 - Tries to reduce the impact of less contributing feature, 
    -but it doesn't eliminate the feature completely
    -Shrinks weights smoothly toward zero but rarely exactly zero. Good default.
    -L2 is used in cases where there are dependent functions (features) and the variance is high 

Elastic Net — mix of L1 + L2.
